Le robot qui se perd

Page créée avec l'aide de Claude (une IA).

⭐ L'idée en 1 phrase

Le robot tourne en rond dans de fausses pages, et ne trouve jamais rien d'utile.

⭐ Ce que je montre

1. J'ouvre la page.
2. J'appuie sur « Lancer le robot ».
3. Je regarde les nombres monter :
  pages lues      →  monte
  mots copiés     →  monte
  pages utiles    →  reste à 0

⭐ Ce que je dis (3 phrases)

1. « Des robots copient les sites web pour entraîner des IA. »
2. « Ici, je lui donne des fausses pages. Chaque page l'envoie vers d'autres fausses pages. »
3. « Il copie beaucoup, mais rien ne sert à quelque chose. »

⭐ Comment ça marche (si on me demande)

  Le robot lit une page  →  passe à une autre  →  recommence

C'est tout. Il ne trouve jamais de dernière page.

⭐ Si on me pose une question

Une petite page qui montre comment on fait tourner un robot en rond.

Ça marche pour de vrai ?
C'est une démonstration simplifiée. Un vrai piège se place sur un vrai site, et certains robots savent l'éviter.
